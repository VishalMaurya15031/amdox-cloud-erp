# Amdox Technologies AI-Powered Cloud ERP Suite

A comprehensive enterprise-grade Cloud ERP Suite built with React (Vite), Node.js, Express, Prisma, and SQLite/PostgreSQL.

## Features
- **Core HR & Payroll**
- **AI Inventory & Supply Chain**
- **Finance & Accounting**
- **Sales & CRM**
- **Role-Based Access Control (RBAC)**
- **Modern Dark Mode Glassmorphism UI**

## Setup Instructions

### Frontend
1. cd frontend
2. npm install
3. npm run dev

### Backend
1. cd backend
2. npm install
3. npx prisma db push
4. node server.js
